Ejercicio 1 — Variables básicas
Crea un programa de consola que declare variables para representar una unidad simple: un string para el nombre, un int para la posición X, un int para la posición Y, y un bool para si está activa. Imprime todo con Console.WriteLine.


Ejercicio 2 — Conversión de tipos
Pide por teclado (Console.ReadLine()) dos números como texto, conviértelos a int (investiga int.Parse o Convert.ToInt32), súmalos, e imprime el resultado.


Ejercicio 3 — Tipos y límites
Investiga qué pasa si intentas guardar el número 300 en una variable de tipo byte. ¿Da error de compilación o de ejecución? Anota la diferencia entre int, long, float, double — cuándo usarías cada uno.
