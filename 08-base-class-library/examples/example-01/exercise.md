# Ejercicio 01 - Tirada de dados

Se te pide simular una pequeña tirada de dados y analizar el resultado.

Requisitos:

1. Crea una instancia de `Random`.
2. Genera 3 tiradas de un dado de 6 caras (valores entre 1 y 6, ambos incluidos) y guárdalas en un array de `int`.
3. Muestra las 3 tiradas por consola.
4. Calcula y muestra cuál fue el valor más alto de las 3 tiradas.
5. Calcula y muestra la diferencia (en valor absoluto) entre la tirada más alta y la más baja.
6. Genera también un número decimal aleatorio entre 0.0 y 1.0, represéntalo como una probabilidad en tanto por ciento (multiplicando por 100), y muéstralo redondeado a 1 decimal.

No hace falta ningún bucle para las 3 tiradas si no lo necesitas — con 3 llamadas independientes es suficiente para este ejercicio.
